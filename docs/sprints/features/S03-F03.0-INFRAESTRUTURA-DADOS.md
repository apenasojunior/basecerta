### **GRUPO 1: Insights Core (F03 - CRÍTICO)**

#### **1.1 insights_cache**
**Propósito:** Armazenar insights pré-calculados (setores, estados, capital)  
**Usado por:** P1, P3, P4, P6

```sql
CREATE TABLE public.insights_cache (
    id SERIAL PRIMARY KEY,
    insight_key VARCHAR(50) UNIQUE NOT NULL,
    categoria VARCHAR(20) NOT NULL CHECK (categoria IN ('setor', 'estado', 'capital')),
    titulo VARCHAR(200) NOT NULL,
    total_empresas INTEGER NOT NULL,
    percentual NUMERIC(5, 2),
    metadata JSONB NOT NULL DEFAULT '{}',
    filters JSONB NOT NULL DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_by VARCHAR(100) DEFAULT 'system'
);

CREATE INDEX idx_insights_categoria ON public.insights_cache(categoria);
CREATE INDEX idx_insights_key ON public.insights_cache(insight_key);
CREATE INDEX idx_insights_updated ON public.insights_cache(updated_at DESC);
```

**Campos `metadata` (JSONB):**
```json
{
  "icone": "💻",
  "demanda_score": 85,
  "o_que_compram": ["Software", "Hardware"],
  "ticket_medio_min": 5000,
  "ticket_medio_max": 50000,
  "rank": 1,
  "top_setores": ["Tecnologia", "Serviços"],
  "perfil": "Médio/Grande Porte",
  "ciclo_venda": "30-60 dias"
}
```

**Dados iniciais:** 15-20 insights (seed)

#### **1.2 insights_history**
**Propósito:** Histórico de evolução dos insights (12+ meses)  
**Usado por:** P6 (Evolução Temporal)

```sql
CREATE TABLE public.insights_history (
    id SERIAL PRIMARY KEY,
    insight_key VARCHAR(50) NOT NULL,
    total_empresas INTEGER NOT NULL,
    percentual NUMERIC(5, 2),
    snapshot_date DATE NOT NULL,
    year_month VARCHAR(7) NOT NULL, -- 'YYYY-MM'
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT fk_insight FOREIGN KEY (insight_key) 
        REFERENCES public.insights_cache(insight_key) ON DELETE CASCADE
);

CREATE INDEX idx_history_key ON public.insights_history(insight_key);
CREATE INDEX idx_history_date ON public.insights_history(snapshot_date DESC);
CREATE INDEX idx_history_month ON public.insights_history(year_month);
CREATE UNIQUE INDEX idx_history_key_month ON public.insights_history(insight_key, year_month);
```

**Dados iniciais:** 12 meses de histórico para cada insight (seed)

### **GRUPO 2: Usuários e Preferências (F04)**

#### **2.1 users**
**Propósito:** Dados dos usuários da plataforma  
**Usado por:** P2, P10

```sql
CREATE TABLE public.users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    name VARCHAR(200) NOT NULL,
    company VARCHAR(200),
    role VARCHAR(50) DEFAULT 'user' CHECK (role IN ('user', 'admin', 'analyst')),
    plan VARCHAR(50) DEFAULT 'free' CHECK (plan IN ('free', 'basic', 'pro', 'enterprise')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    last_login TIMESTAMP WITH TIME ZONE,
    is_active BOOLEAN DEFAULT TRUE
);

CREATE INDEX idx_users_email ON public.users(email);
CREATE INDEX idx_users_active ON public.users(is_active) WHERE is_active = TRUE;
```

**Dados iniciais:** 3-5 usuários demo (seed)

### **GRUPO 6: Busca NLP (F05)**

#### **6.1 nlp_queries**
**Propósito:** Cache de queries NLP processadas  
**Usado por:** P7 (Busca NLP)

```sql
CREATE TABLE public.nlp_queries (
    id SERIAL PRIMARY KEY,
    user_id UUID,
    query_text TEXT NOT NULL,
    query_hash VARCHAR(64) UNIQUE NOT NULL, -- MD5 da query normalizada
    intent VARCHAR(100), -- 'search_sector', 'compare', 'trending', etc.
    extracted_params JSONB, -- Parâmetros extraídos pela IA
    matched_insights JSONB, -- Array de insight_keys
    ai_response TEXT,
    expires_at TIMESTAMP WITH TIME ZONE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT fk_user FOREIGN KEY (user_id) 
        REFERENCES public.users(id) ON DELETE SET NULL
);

CREATE INDEX idx_nlp_hash ON public.nlp_queries(query_hash);
CREATE INDEX idx_nlp_expires ON public.nlp_queries(expires_at);
CREATE INDEX idx_nlp_created ON public.nlp_queries(created_at DESC);
```

**Exemplo:**
```json
{
  "intent": "search_sector_state",
  "extracted_params": {
    "sector": "tecnologia",
    "state": "SP",
    "growth_filter": "> 20%"
  },
  "matched_insights": ["setor_tecnologia", "estado_sp"]
}
```
